# **App Name**: KitaMo

## Core Features:

- Secure User Authentication: Enable secure user sign-up and login functionality.
- Record Transactions: Allow users to easily record their income and expenses with categorization.
- Referral Code Generation: Generate a unique referral code for each user to share with others.
- Referred Users Tracking: Tool to track users who have signed up using your referral code.
- Financial Summary: Present a summary of personal finances (income vs. expenses) in charts.
- AI-Powered Financial Tips: AI powered personal finance tip based on spending and income history. A tool for understanding the users financial behaviours

## Style Guidelines:

- Primary color: Soft blue (#64B5F6) for a calming and trustworthy feel. This evokes reliability and stability.
- Background color: Light blue (#E3F2FD), very desaturated, creates a clean, open and professional canvas
- Accent color: Deep blue (#1976D2) used sparingly to draw attention to calls to action
- Font: 'Inter', sans-serif. It has a modern, machined, objective, neutral look, which is suitable for finance apps.
- Use minimalistic icons to represent different categories of income and expenses.
- A clean, well-spaced layout for financial information. A top navigation for general summaries with cards.
- Subtle transitions when loading new data or updating charts.
